## 安装与更新

首次安装打开 APK 并按系统提示安装；已有用户直接覆盖安装同包名同签名的新 APK，**不要卸载或清除应用数据**。更新沿用原数据库和文件目录，保留缓存、自定义任务、附件及设置。JSON 导出不包含附件文件、登录资料、提醒和壁纸设置，换机需另行保存这些内容。

## 功能

- 中文整学期课表、13 节等距周视图、日视图与课堂回放入口。
- 本学期课程、作业、资料和提交状态，考试分类及月日程。
- 本地自定义任务、完成状态和附件，先显示已保存缓存再同步更新。
- 每天/每周通知提醒，按系统权限显示应用横幅；我的中设置壁纸，地图始终不使用壁纸。
- 离线良乡地图、双指缩放与拖动，内置仓耳今楷02-W04 字体。

一个校园登录入口接续学校系统；学校要求验证码/重新认证时仍需手动处理。本应用为非学校官方工具，不代交作业。不在分发仓库上传任何用户内容或登录信息。
